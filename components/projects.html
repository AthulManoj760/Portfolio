A personal expense tracking web application that helps users manage their daily spending efficiently. Users can add, categorize, and monitor expenses with a clean and intuitive interface, making it easier to understand spending patterns and control budgets.

  • Categorize expenses (Food, Travel, Bills, etc.)
  • Monthly expense tracking and summaries
  • Simple dashboard for quick insights
  • Responsive design for mobile and desktop

KTU Q-GEN

An AI question paper generator focusing primarily on internal exams. Where each question is based on course outcomes of individual subjects and within their syllabus.

Tech Stack
  • Frontend: React 19, Vite, Tailwind CSS, Lucide icons.
  • Backend: Django 5 / 6, Django REST Framework, WhiteNoise.
  • AI Engine: HuggingFace Inference API (Meta-Llama-3-8B-Instruct).
  • Database: SQLite (Development) / PostgreSQL (Optional Production).
  • DevOps: GitHub Actions (CI), Docker, Docker Compose.
